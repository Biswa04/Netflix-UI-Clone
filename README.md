# Netflix Clone

A responsive frontend recreation of Netflix's streaming platform interface using HTML and CSS. This project focuses on replicating Netflix's visual appearance, including its homepage layout, featured content, movie thumbnails, and navigation elements, with a responsive design that adapts to different screen sizes while strengthening HTML and CSS design skills.

## Features

- Netflix-inspired homepage design.
- Navigation bar with movie and TV show sections.
- Attractive hero section with featured content.
- Movie and TV show browsing interface.
- Email input field for visual demonstration only.
- Sign In and Get Started buttons for UI demonstration only.
- Responsive user interface.

## Technologies Used

- HTML5
- CSS3

## How to Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Explore the Netflix-inspired user interface!
